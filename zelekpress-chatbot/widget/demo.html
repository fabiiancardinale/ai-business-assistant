Ferretería Don José

Un sitio cualquiera (simulado) donde instalamos el chatbot.

Este es el sitio de un cliente. Los estilos de esta página (Georgia, azul, etc.) NO afectan al widget, porque el widget vive dentro de un Shadow DOM aislado.

Cómo se instala: se pega este código antes de </body> — nada más. 
<script
  src="https://app.zelekpress.com/widget/widget.js"
  data-chatbot-id="1"
  data-api="https://api.zelekpress.com"></script>

Abajo a la derecha (o izquierda, según la config) aparece el botón del chat. Hacé clic para probarlo.
